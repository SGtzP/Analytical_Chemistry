# Polynuclear Metal Hydroxide and Ligand Protonation Fraction Diagram

This Python script calculates and plots the fraction distribution diagrams (alpha fractions) for a metal hydroxide system and a ligand protonation system over a pH range. It supports multiple hydroxo species for metals and multiple protonation states for ligands, with automatic labeling and clear visualization.

## Features

- Calculates alpha fractions for metal hydroxide complexes based on cumulative base constants (logβ).
- Calculates alpha fractions for ligand protonation states based on cumulative protonation constants.
- Automatically generates chemical species labels with proper charge formatting.
- Produces high-DPI plots of species fractions vs. pH.
- Fully customizable input parameters for metals and ligands.
